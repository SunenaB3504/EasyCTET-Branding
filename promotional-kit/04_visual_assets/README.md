# 🖼️ Visual Assets Folder

Store your launch creative files in this folder for easy access:

1. **`app_icon_512.png`** — High-res EasyCTET application icon.
2. **`feature_graphic_1024x500.png`** — Play Store banner / promo banner.
3. **`playstore_qr_code.png`** — Direct QR code linking to `https://play.google.com/store/apps/details?id=com.easyctet.app`.
4. **`screenshots/`** — Highlight shots of the 150-Q mock test, offline prompt, and score analysis for WhatsApp status flyers.
